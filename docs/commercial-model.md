# Commercial Model

## Plans

### Free — $0

A fast, clean place to keep links. Save them and come back to them later.

| Dimension | Limit | Overage |
|---|---|---|
| Saved links | 100 lifetime (WEB, YOUTUBE, PDF, AUDIO) | Hard stop |

**Included features**
- Save links of any type (Web, YouTube, PDF, Audio)
- Search across saved titles, domains, and descriptions
- Basic metadata (title, favicon, description, thumbnail)
- REST API and MCP access

**Not included**
- File uploads (PDF, audio)

---

### Pro — $39 one-time

No limits on what you keep.

**New accounts start with a 7-day Pro trial — no card required.** After the trial, the account downgrades to Free unless the one-time payment is made.

| Dimension | Limit | Overage |
|---|---|---|
| Saved links | Unlimited | — |

**Included features**
- Everything in Free
- Unlimited saved links
- PDF & audio file uploads

---

## Key decisions

**Why one-time payment instead of subscription?**
Personal productivity tools with a one-time purchase convert better and retain more goodwill. With no AI compute per user, serving cost is just storage and bandwidth, so a one-time fee is sustainable.

**Why did the AI features go away?**
Purl was reframed from an AI knowledge base into a home for your "pearls". The in-app chat, BYOK, content extraction, transcripts, embeddings, and semantic search were removed, along with their monthly caps. Pro's value and pricing are due for a revisit as part of that reframe.
